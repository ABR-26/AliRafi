`Python` `Azure Functions` `KQL` `Managed Identity` `Log Analytics`

---

### 🔗 Cross-Tenant Diagnostic Settings Automation
PowerShell automation for configuring Azure diagnostic settings across 50+ external customer tenants via Azure Lighthouse. Inclusion-based subscription filtering, multi-tenant SPN authentication, and centralized Sentinel log forwarding.
`PowerShell` `Azure Lighthouse` `ARM` `Multi-Tenant` `Monitoring Contributor`
